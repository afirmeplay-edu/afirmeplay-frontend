SISTEMA DE CERTIFICAÇÃO DE LIMOEIRO DE ANADIA — TEMA AFIRMEPLAY

ARQUIVO PRINCIPAL
  Sistema_Certificacao_Limoeiro_AFIRMEPLAY.html

USO
1. Extraia o ZIP e abra o arquivo HTML no Google Chrome.
2. O certificado oficial mantém a arte municipal azul e dourada.
3. Somente as cores do painel administrativo (cabeçalho, campos,
   bordas, botões e tabelas) foram atualizadas para o padrão AfirmePlay.
4. O PDF individual, PDF em lote, assinatura importada, QR Code,
   inclusão/remoção de encontros e importação CSV foram preservados.
5. Modelo_Nomes_Certificados_Limoeiro.csv pode ser usado no upload.

IMPORTANTE
- O HTML é independente: não é necessário carregar o CSS separado.
- O arquivo CSS serve como referência para quem edita o sistema.
- Os cadastros são armazenados no navegador utilizado; faça backup CSV
  dos participantes antes de substituir a versão em uso.
- QR Code com autenticação pública depende de URL de validação conectada
  a um serviço de verificação real.
